# Zombicide: Gear Up 助手

[English](README.md) | [한국어](README.ko.md) | [日本語](README.ja.md) | **中文**

这是一个网页应用，可以代替玩家为桌游《Zombicide: Gear Up》洗混并摆放回合卡、刷怪卡和首领卡。

立即使用: https://bluekms.github.io/zombicide-gearup-helper/

## 使用方法

- 按下屏幕下方的设置按钮，卡牌会被洗混并背面朝上摆放在 9 个格子中。
- 点击卡牌即可将其翻到正面。
- 用右上角的按钮切换浅色/深色主题。默认跟随设备设置，并会记住你选择的主题。

## 阶段设置

所有设置都会生成 9 个格子，并在每个格子的上排放 1 张回合卡。回合卡共有 10 张，因此有 1 张不使用。

### 回合卡构成

| 编号 | 颜色 | 符号 | 同伴 |
|---|---|---|---|
| 1 | 蓝 | x | |
| 2 | 黄 | >, >> | |
| 3 | 红 | >> | |
| 4 | 绿 | x | |
| 5 | 红 | > | |
| 6 | 绿 | >> | 有 |
| 7 | 绿 | > | |
| 8 | 蓝 | > | 有 |
| 9 | 红 | >> | 有 |
| 10 | 蓝 | >> | |

### Easy 1 Phase Setup

- 第 1～9 格上排: 回合卡 9 张
- 第 3～9 格下排: 刷怪卡 7 张（A 3 张、B 2 张、C 2 张）
- 不使用的回合卡一定是 3、5、7、10 号中的一张。也就是说，x 卡（1、4 号）、黄色卡（2 号）和同伴卡（6、8、9 号）一定会被摆放。

### Normal 1 Phase Setup

- 格子的构成与 Easy 1 Phase Setup 相同。
- 不使用的回合卡是 10 张中随机的 1 张。

### 2 Phase Setup

- 第 1～9 格上排: 回合卡 9 张（不使用的 1 张为随机，不区分难度）
- 第 3～5 格下排: 第 1 阶段首领卡 3 张
- 第 6～9 格下排: 第 2 阶段首领卡 4 张
- 不使用刷怪卡。
