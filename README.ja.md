# Zombicide: Gear Up ヘルパー

[English](README.md) | [한국어](README.ko.md) | **日本語** | [中文](README.zh.md)

ボードゲーム『Zombicide: Gear Up』のターンカード、スポーンカード、ボスカードを代わりにシャッフルして並べるウェブアプリです。

すぐに使う: https://bluekms.github.io/zombicide-gearup-helper/

## 使い方

- 画面下のセットアップボタンを押すと、カードをシャッフルして9つの枠に裏向きで並べます。
- カードをタップすると表向きに裏返ります。
- 右上のボタンでライト/ダークテーマを切り替えます。最初は端末の設定に従い、選んだテーマは記憶されます。

## フェーズ設定

すべてのセットアップは9つの枠を作り、各枠の上段にターンカードを1枚ずつ置きます。ターンカードは10枚あるので、1枚は使いません。

### ターンカードの構成

| 番号 | 色 | 記号 | 仲間 |
|---|---|---|---|
| 1 | 青 | x | |
| 2 | 黄 | >, >> | |
| 3 | 赤 | >> | |
| 4 | 緑 | x | |
| 5 | 赤 | > | |
| 6 | 緑 | >> | あり |
| 7 | 緑 | > | |
| 8 | 青 | > | あり |
| 9 | 赤 | >> | あり |
| 10 | 青 | >> | |

### Easy 1 Phase Setup

- 1～9番目の枠の上段: ターンカード9枚
- 3～9番目の枠の下段: スポーンカード7枚（A 3枚、B 2枚、C 2枚）
- 使わないターンカードは必ず3、5、7、10番のいずれかです。つまり x カード（1、4番）、黄色のカード（2番）、仲間カード（6、8、9番）は必ず置かれます。

### Normal 1 Phase Setup

- 枠の構成は Easy 1 Phase Setup と同じです。
- 使わないターンカードは10枚の中からランダムな1枚です。

### 2 Phase Setup

- 1～9番目の枠の上段: ターンカード9枚（使わない1枚はランダムで、難易度の区別はありません）
- 3～5番目の枠の下段: フェーズ1ボスカード3枚
- 6～9番目の枠の下段: フェーズ2ボスカード4枚
- スポーンカードは使いません。
