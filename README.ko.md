# 좀비사이드: 무기를 들어라 헬퍼

[English](README.md) | **한국어** | [日本語](README.ja.md) | [中文](README.zh.md)

보드게임 《좀비사이드: 무기를 들어라》의 턴 카드, 스폰 카드, 보스 카드를 대신 섞어서 놓아 주는 웹 앱입니다.

바로 사용하기: https://bluekms.github.io/zombicide-gearup-helper/

## 사용법

- 화면 아래의 셋업 버튼을 누르면 카드를 섞어 9칸에 뒷면으로 놓습니다.
- 카드를 누르면 앞면으로 뒤집힙니다.
- 오른쪽 위 버튼으로 라이트/다크 테마를 바꿉니다. 처음에는 기기 설정을 따르고, 고른 테마는 기억합니다.

## 페이즈 설정

모든 셋업은 9칸을 만들고, 각 칸 윗줄에 턴 카드를 1장씩 놓습니다. 턴 카드는 10장이므로 1장은 쓰지 않습니다.

### 턴 카드 구성

| 번호 | 색 | 기호 | 동료 |
|---|---|---|---|
| 1 | 파랑 | x | |
| 2 | 노랑 | >, >> | |
| 3 | 빨강 | >> | |
| 4 | 초록 | x | |
| 5 | 빨강 | > | |
| 6 | 초록 | >> | 있음 |
| 7 | 초록 | > | |
| 8 | 파랑 | > | 있음 |
| 9 | 빨강 | >> | 있음 |
| 10 | 파랑 | >> | |

### Easy 1 Phase Setup

- 1~9번째 칸 윗줄: 턴 카드 9장
- 3~9번째 칸 아랫줄: 스폰 카드 7장 (A 3장, B 2장, C 2장)
- 쓰지 않는 턴 카드는 항상 3, 5, 7, 10번 중 하나입니다. 즉 x 카드(1, 4번), 노랑 카드(2번), 동료 카드(6, 8, 9번)는 항상 놓입니다.

### Normal 1 Phase Setup

- 칸 구성은 Easy 1 Phase Setup과 같습니다.
- 쓰지 않는 턴 카드는 10장 중 무작위 1장입니다.

### 2 Phase Setup

- 1~9번째 칸 윗줄: 턴 카드 9장 (쓰지 않는 1장은 무작위이며 난이도 구분이 없습니다)
- 3~5번째 칸 아랫줄: 1페이즈 보스 카드 3장
- 6~9번째 칸 아랫줄: 2페이즈 보스 카드 4장
- 스폰 카드는 쓰지 않습니다.
